Building My
Portfolio Website

Written by Nadir  ·  Last Month

Orientation

Last month, I decided to build my own portfolio website — a place to showcase my work and support my career in school. It was a big goal, and I knew it would take real time and effort. So I committed fully: long hours designing, experimenting, and developing every detail until it felt right.

01

Designing in Figma

First of all, I opened Figma and started sketching the layout. I experimented with different color palettes, font choices, and section structures. Designing first helped me have a clear vision before touching a single line of code — it saved me a lot of confusion later.

02

Writing the Code

Then I moved into development. I wrote the HTML, CSS, and a bit of JavaScript to bring the design to life. This was where I grew the most — every line of code taught me something new. It was exciting to see static mockups transform into a real, interactive website running in the browser.

03

Facing Errors (and Fixing Them)

Of course, the journey was not without challenges. It was not uncommon to encounter many errors while typing code — broken layouts, elements that refused to align, and scripts that simply would not run. But I learned that every problem has a solution. I stayed patient, searched for answers, and fixed each bug one by one.

Reorientation

I am very pleased with the result. After so much hard work, my website is officially launched — and it looks so professional. I feel more confident presenting myself and my work now. This experience taught me that building something from scratch, no matter how difficult, is one of the most rewarding things I have ever done.
